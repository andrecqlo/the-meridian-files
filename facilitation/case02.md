# Case 02 — The Replay · facilitator notes

*Someone just resigned. The project loses a month. The board meets in 15 minutes.*

Not built. This file exists so the ground rules are written down before the
case is, because this one needs them.

## Ground rules — non-negotiable

1. **Discuss patterns, not people.** The case is about what a record shows and
   what it leaves out, not about anyone in the room. If the conversation turns
   to a named colleague, stop it and return to the record.
2. **Disclose the topic in advance — this case only.** Case 01 depends on a
   surprise reveal. This one does not, and the material is close enough to
   people's own experience that arriving unwarned is not fair. Tell people what
   the session is about before they agree to attend, and let anyone opt out
   without explaining why.
3. **Do not run it in a team with a live grievance**, a current investigation,
   or an unresolved departure. Wait. The case will still be there.

## Intended position in the series

Second. It follows Case 01 and assumes the group has already had the reveal, so
it can be run openly.
